# Python Projects

This folder contains data analysis projects developed using Python, focusing on
data cleaning, exploratory data analysis (EDA), feature engineering, and
business-driven insights.

The projects are built on realistic datasets (50k–90k+ rows) and aim to
demonstrate practical data analytics skills rather than theoretical modeling.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Skills Demonstrated
- Data cleaning and preprocessing
- Handling missing values and outliers
- Feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Business insight generation

## Project Types
- Customer transaction analysis
- Credit and spending behavior analysis
- Risk and trend identification
- Data-driven reporting and storytelling

Each project folder includes:
- A dedicated README explaining the project
- Jupyter Notebook(s) with analysis
- Cleaned dataset or outputs (where applicable)
