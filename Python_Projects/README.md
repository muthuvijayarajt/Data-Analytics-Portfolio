# Customer Transaction Analysis (Python)

## Overview
This project focuses on analyzing customer transaction data using Python to
understand spending behavior, credit usage patterns, and risk indicators.

The analysis follows a complete data analytics workflow — from raw data
inspection and cleaning to exploratory data analysis (EDA) and visualization.

## Dataset
- Size: ~50,000–90,000 transaction records
- Domain: Customer transactions & credit behavior
- Data includes:
  - Customer details
  - Transaction amounts
  - Credit limits and balances
  - Payment status
  - Rewards and usage metrics
  - Transaction dates and categories

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
- Loaded and inspected raw transaction data
- Cleaned missing values and handled inconsistencies
- Converted date columns and corrected data types
- Performed feature engineering such as:
  - Credit utilization percentage
  - Spending category classification
  - Payment delay flags
- Conducted Exploratory Data Analysis (EDA) to identify trends and patterns
- Created visualizations to support business insights

## Key Analysis & Insights
- Customer spending distribution and transaction trends
- Credit utilization patterns across customers
- Late payment and risk-related behavior analysis
- Category-level and time-based transaction insights
- Identification of high-spending and high-risk segments

## Files
- `analysis.ipynb` – Jupyter Notebook containing the full analysis
- `cleaned_dataset.csv` – Cleaned dataset used for final analysis (if included)

## Highlights
- Worked with a large, realistic transactional dataset
- Applied structured EDA and data cleaning techniques
