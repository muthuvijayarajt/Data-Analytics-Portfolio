# 📊 Sales Performance Dashboard (Jan – Jun 2025)

## 📌 Project Overview
This project is an **Excel-based Sales Performance Dashboard** designed to analyze and visualize sales data across **products, regions, sales channels, and time**. The dashboard transforms raw transactional data into meaningful business insights using Excel formulas, pivot tables, and charts.

The analysis covers sales from **January to June 2025**.

---

## 📂 Dataset Description
The dataset contains **100 sales transactions**, where each row represents a single order.

### Columns:
- Order ID  
- Order Date  
- Customer Name  
- Region (North, South, East, West)  
- Product  
- Product Category (Electronics, Computers, Accessories)  
- Sales Channel (Online / Retail Store)  
- Units Sold  
- Unit Price  

---

## 🧮 Calculated Metrics
- **Total Sales** = Units Sold × Unit Price  
- **Cost Price** = Estimated cost per order  
- **Profit** = Total Sales − Cost Price  
- **Profit Margin (%)** = (Profit ÷ Total Sales) × 100  
- **Average Order Value (AOV)** = Total Sales ÷ Number of Orders
