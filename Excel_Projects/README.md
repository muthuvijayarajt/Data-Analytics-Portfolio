# Excel Projects

This folder contains data analysis projects built using Microsoft Excel,
focusing on formula-based analysis, data cleaning, and KPI calculations.

The projects demonstrate strong fundamentals in Excel without relying on
advanced tools such as macros or Power Query, emphasizing core analytical
thinking and logic.

## Skills & Techniques Used
- Excel formulas and functions
- Lookups (VLOOKUP / XLOOKUP)
- Conditional logic (IF, AND, OR)
- Text functions
- Date functions
- Aggregations (SUM, AVERAGE, COUNT)
- KPI calculation
- Data cleaning and validation

## Project Types
- Sales KPI and performance analysis
- Employee salary and bonus analysis

Each project folder includes:
- A dedicated README explaining the analysis
- Excel file containing the complete solution
