# 📊 Employee Salary Report – Excel Project

## 📌 Project Overview
This project is an **Excel-based Employee Salary Report** created to analyze employee data across **departments, locations, joining dates, and salary levels**.  
The report helps understand workforce distribution, compensation patterns, and departmental salary trends using structured Excel analysis.

The dataset contains **100 employee records**, making it suitable for realistic HR analytics practice.

---

## 📂 Dataset Description
Each row represents a single employee.

### Columns Included:
- **Employee ID** – Unique identifier for each employee  
- **Employee Name** – Name of the employee  
- **Department** – Finance, HR, IT, Marketing, Sales, Support  
- **Date of Joining** – Employee joining date  
- **Location** – Bangalore, Chennai, Mumbai, Delhi, Pune, Hyderabad  
- **Basic Salary** – Monthly salary in INR  

---

## 🧮 Analysis & Calculations
The Excel file performs analysis using formulas and structured logic to derive insights such as:

- Department-wise salary distribution  
- Location-wise employee strength  
- Identification of high and low salary ranges  
- Workforce spread across cities  
- Hiring trends based on joining dates  

---

## 📊 Key Insights
- Finance and IT departments generally have higher salary ranges  
- Major workforce concentration is in Bangalore, Mumbai, and Chennai  
- Balanced hiring observed across multiple departments  
- Salary variation reflects department roles and responsibilities  

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel  
- Excel formulas  
- Sorting & filtering  
- Tabular data analysis  

---

## 🔄 How to Use / Update
1. Add new employee records below the existing data  
2. Ensure formulas extend to new rows if applicable  
3. Review summaries after updating the dataset  

---

## 📌 Assumptions
- Salaries are monthly and in Indian Rupees (₹)  
- Employee IDs are unique  
- Dates follow DD/MM/YYYY format  

---

## 🎯 Project Objective
To demonstrate **Excel data analysis skills** by converting raw employee data into structured insights useful for HR and management decision-making.
