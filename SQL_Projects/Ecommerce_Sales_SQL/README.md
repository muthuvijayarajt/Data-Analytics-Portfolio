# E-Commerce SQL Analysis Project

## Overview
This project analyzes a large-scale E-commerce dataset containing approximately **90,000 records** to derive meaningful business insights using **MySQL**.  
The analysis focuses on sales performance, customer behavior, product trends, and operational efficiency.

This project demonstrates strong SQL fundamentals along with advanced querying techniques commonly used in real-world data analytics roles.

---

## Dataset Details
- Domain: E-Commerce
- Records: ~90,000 rows
- Format: SQL-compatible dataset
- Data includes:
  - Orders
  - Customers
  - Products
  - Categories
  - Payments
  - Order dates and sales values

---

## Skills & Concepts Used
- Joins (INNER, LEFT)
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregations
- Date & Time Analysis
- Data Cleaning
- Performance-oriented queries

## Analysis Performed
- Sales trends over time
- Top-selling products and categories
- Customer purchase behavior
- Revenue contribution by category
- Order frequency and value analysis
- Ranking products and customers using window functions
